# Taskezy system requirements

The system requirements document for Taskezy, a SaaS platform for real estate teams, laid out as a one-page site so it is easier to read than the Word file. It covers the platform architecture and the economics behind it.

Live: https://taskesy-srs.vercel.app

The page is a single `index.html` with no build step. Open it in a browser or serve the folder with any static server.

The original document, `TASKEZY_Enterprise_SRD V1.0.docx`, is in the repo too.
